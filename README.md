# KeyLock

A simple desktop utility that temporarily disables your keyboard input so you can clean your keyboard without accidentally triggering keystrokes or shortcuts.

Built with Python and tkinter.

## Features

- One-click keyboard lock and unlock
- Minimal interface — just open and use
- No installation required beyond Python
- Cross-platform (Windows, macOS, Linux)

## Requirements

- Python 3.x
- tkinter (included with most Python installations)

## How to Run

## How to Use

1. Open the app
2. Click **Start** to lock your keyboard
3. Clean your keyboard safely
4. Click **Stop** to restore keyboard input
